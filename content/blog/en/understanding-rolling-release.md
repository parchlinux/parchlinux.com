A rolling-release system receives package updates continuously instead of moving between large, isolated operating-system versions.

## The main difference

Traditional versioned distributions tend to keep a defined release stable for a period and later move users to the next major release. Rolling systems evolve the existing installation over time.

## Why people like it

Developers and enthusiasts often value relatively recent compilers, libraries, desktop environments and applications.

## Useful habits

- Do not postpone updates for very long periods.
- Keep backups of important data.
- Read package-manager messages.
- Understand the source of third-party packages before installing them.
