A fresh Linux installation can make you want to customize everything immediately. A better first step is to learn the default system, update it, and only then make deliberate changes.

## Start with an update

Keeping packages current is one of the simplest habits you can build.

```bash
sudo pacman -Syu
```

> You do not need to memorize every command. Knowing where to verify a command and read its documentation is more useful.

## Install what you actually use

Start with a short list: your browser, communication tools, editor, media applications and backup utilities. Add more software when a real need appears.

## Use documentation as part of the workflow

Read the full error, capture the exact message and check the documentation before changing several unrelated settings at once.

### Ask reproducible questions

When you ask the community for help, include the system version, desktop environment, exact error and the steps that produced it.
