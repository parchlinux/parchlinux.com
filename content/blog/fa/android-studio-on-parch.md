سلام! توی این فرسته از بلاگ پارچ می‌خواهیم آموزش نصب اندروید استودیو روی پارچ رو به ساده‌ترین شکل ممکن بدیم. پس با ما همراه باشید.

![image 1024x576](/blog/fa/android-studio-on-parch/cover.png)

### اول باید مخازن Chaotic-AUR رو فعال کنیم

پارچ لینوکس به صورت پیش‌فرض اندروید استودیو رو داخل مخازن رسمی خودش نداره، ولی خوشبختانه Chaotic-AUR این بسته رو همیشه به‌روز داره و نصبش خیلی راحت‌تر از ساخت دستی از AUR معمولیه.

برای فعال کردنش فقط کافیه دو تا دستور رو توی ترمینال بزنید:

اول این رو بزنید و اینتر کنید (رمز عبورتون رو می‌خواد):

```bash
sudo pacman -S chaotic-aur
```

بعدش این یکی رو بزنید:

```bash
sudo chaotic-install
```

این دو تا دستور مخازن Chaotic-AUR رو به سیستم اضافه می‌کنن و کلیدهای لازم رو هم وارد می‌کنن. دیگه کاری ندارید، تمام!

### حالا وقت نصب خود اندروید استودیو و ابزارهای لازمشه

ترمینال رو باز کنید و فقط یک خط دستور خیلی طولانی رو کپی کنید و وارد کنید (همه‌چیز با هم نصب میشه):

```bash
sudo pacman -S android-studio android-sdk-cmdline-tools-latest android-sdk android-sdk-build-tools android-sdk-platform-tools android-platform android-emulator
```

وقتی ازتون پرسید آیا می‌خواهید ادامه بدید، y بزنید و اینتر کنید. صبر کنید تا دانلود و نصب تموم بشه (حجمش زیاده، بسته به سرعت اینترنتتون ممکنه نیم ساعت یا بیشتر طول بکشه).

بعد از اینکه نصب تموم شد، اندروید استودیو رو می‌تونید از منوی برنامه‌ها باز کنید یا توی ترمینال تایپ کنید:

```bash
android-studio
```

اولین بار که بازش می‌کنید، خودش می‌پرسه که SDK رو کجا دانلود کنه. پیش‌فرض معمولاً `/opt/android-sdk` هست، همون رو قبول کنید و ادامه بدید.

### یه مشکل کوچیک هست: دسترسی به پوشه SDK

چون SDK توی مسیر `/opt/android-sdk` نصب میشه و این مسیر متعلق به root هست، وقتی می‌خواهید پروژه بسازید یا emulator اجرا کنید ممکنه ارور دسترسی بگیرید. برای اینکه دیگه هیچ مشکلی نداشته باشید، فقط یک دستور ساده بزنید (به جای username اسم کاربری خودتون رو بنویسید، مثلاً اگر اسمتون ali هست بنویسید ali):

```bash
sudo chown -R username:username /opt/android-sdk/*
```

مثال واقعی:

```bash
sudo chown -R ali:ali /opt/android-sdk/*
```

این دستور مالکیت تمام فایل‌های داخل پوشه SDK رو به شما میده و دیگه هیچ‌وقت ارور دسترسی نمی‌بینید.

### تمام! حالا چیکار کنیم؟

اندروید استودیو رو باز کنید، اگر اولین باره یه کم صبر کنید تا فایل‌های اولیه دانلود بشه (اینترنتتون باید وصل باشه). بعدش می‌تونید New Project بزنید و شروع کنید به ساختن اپلیکیشن اندرویدی.
